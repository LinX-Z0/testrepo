# Game System Review

## Objective
Evaluate whether a gameplay system achieves
its intended player experience.

## Procedure

1. Identify the intended player experience.
2. Explain the core gameplay loop.
3. Identify the meaningful player decisions.
4. Evaluate risk, reward, and strategic depth.
5. Identify potential exploits or dominant strategies.
6. Assess complexity and cognitive load.
7. Recommend improvements ranked by importance.

## Rules
- Distinguish confirmed issues from hypothetical risks.
- Do not invent mechanics or requirements.
- Ask for missing information only when necessary.
- Do not modify project files unless requested.
- Prioritize actionable recommendations.

## Output
Provide:
- System overview
- Strengths
- Potential design issues
- Recommended improvements
- Assumptions and Unknowns
